  84 ### Nested text (per-segment styling)
  85 
  86 Nest `Text` components to style individual segments differently. This is useful for inline formatting, such as bold or colored words within a sentence.
  87 
  88 > **Note:** Nested text uses SwiftUI's [Text concatenation](https://developer.apple.com/documentation/swiftui/text), so only modifiers that return `Text` (such as `bold`, `italic`, `font`, `foregroundColor`, and `foregroundStyle` with color) will apply to nested segments.
  89 
  90 ![The sentence Hello world! where the word world is bold and red](/static/images/expo-ui/examples/text-nested-ios-light.webp)

 211 ### Custom fonts
 212 
 213 Use the `font` modifier with a `family` parameter to use custom fonts. You can load custom fonts using [`expo-font`](/versions/latest/sdk/font) library.

 294 ### Auto-updating date
 295 
 296 Use the `date` and `dateStyle` props to display a date that automatically updates as time passes. This is especially useful in widgets and Live Activities.
 297 
 298 ![A countdown reading 4 minutes and 53 seconds](/static/images/expo-ui/examples/text-date-ios-light.webp)
 299 
 314 
 315 ### Timer interval
 316 
 317 Use `timerInterval` to display a live countdown or count-up timer. This requires iOS/tvOS 16+.
 318 
 319 ![A countdown reading 9 minutes and 54 seconds](/static/images/expo-ui/examples/text-timer-interval-ios-light.webp)
 320 
 338 
 339 > **Note:** `timerInterval`, `countsDown`, and `pauseTime` require iOS 16.0+ / tvOS 16.0+. On older versions, the timer interval will not render.
