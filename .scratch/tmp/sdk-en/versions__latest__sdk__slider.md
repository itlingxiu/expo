# @react-native-community/slider

> 支持平台：Android、iOS、Web、Expo Go。

:::warning
[`@expo/ui` provides a drop-in replacement](/versions/latest/sdk/ui/drop-in-replacements/slider) for `@react-native-community/slider`, powered by Jetpack Compose on Android and SwiftUI on iOS.
:::

A component library that provides access to the system UI for a slider control, that allows users to pick among a range of values by dragging an anchor.

## Installation

:::tabs
:::tab npm
```sh
npx expo install @react-native-community/slider
```
:::
:::tab yarn
```sh
yarn expo install @react-native-community/slider
```
:::
:::tab pnpm
```sh
pnpm expo install @react-native-community/slider
```
:::
:::tab bun
```sh
bun expo install @react-native-community/slider
```
:::
:::
