# 订阅、套餐与附加项

[Expo Application Services (EAS)](/eas) 对 [EAS Build](/build/introduction) 上有限数量的低优先级构建提供[免费使用](https://expo.dev/acceptable-use#free-plan)，并通过 [EAS Update](/eas-update/introduction) 提供免费更新。这些限额每月重置。

在 Free 套餐之外，还有不同的订阅套餐，以满足各类客户及其需求。每个付费套餐都提供额度，以便为 EAS Build 启用优先构建，并通过更多月活跃用户和额外带宽扩大对 EAS Update 的访问。我们还提供附加项，用来补充订阅，并启用可选择加入的功能以强化客户需求。

本页列出不同的基于订阅的套餐和可用附加项。

## 订阅

订阅按月计费，全球价格相同（税前）。要查看账户当前订阅的套餐，前往[账户的 Billing](https://expo.dev/settings/billing)，在 **Current Plan** 下可以找到当前套餐的详情。

![EAS 仪表板的账单页面显示组织账户的当前套餐。](/static/images/billing/plan-01.png)

你也可以随时取消订阅。更多信息见[取消套餐](/billing/manage#取消套餐)。

我们也会按需提供年度合同。联系[客户支持](https://expo.dev/contact)团队，了解年度套餐是否适合你。

## 套餐

每个套餐都有特定限额。付费套餐的订阅者可以超出限额，并用[按用量计费](/billing/usage-based-pricing)支付额外用量。Free 套餐账户不会产生超额费用。详情见[用完 Free 套餐的每月配额后会发生什么](/billing/faq#用完-free-套餐的每月配额后会发生什么)。

- **[定价](https://expo.dev/pricing)**：访问定价页面，查看每个套餐的当前价格列表。

### Production

Production 套餐面向专业开发者和小型企业。订阅此套餐可以获得：

- 可靠的生产级服务
- 用于 EAS Build 高优先级构建的每月[额度](/billing/usage-based-pricing)
- 更高的 EAS Update 独立用户数、带宽和存储限额

如果超出限额或用完每月额度，后续用量将按[按用量价格](/billing/usage-based-pricing)收费。

### Enterprise

Enterprise 套餐面向拥有大型项目、需要额外资源（例如专属支持）的组织和企业。订阅此套餐可以获得：

- 可靠的生产级服务
- 用于 EAS Build 高优先级构建的每月[额度](/billing/usage-based-pricing)
- 更高的 EAS Update 独立用户数、带宽和存储限额

Enterprise 套餐提供的 EAS Build 每月额度和 EAS Update 带宽远高于其他任何套餐。

如果超出限额或用完每月额度，后续用量将按[按用量价格](/billing/usage-based-pricing)收费。

### Starter

Starter 套餐面向准备发布真实应用的开发者。每月 19 美元，你获得 45 美元的构建额度，可用于优先构建。

订阅 Starter 套餐可以获得：

- 可靠的生产级服务
- 用于 EAS Build 高优先级构建的每月[额度](/billing/usage-based-pricing)
- 超出 Free 套餐的 EAS Update 限额并为额外用量付费的能力

如果超出限额或用完每月额度，后续用量将按[按用量价格](/billing/usage-based-pricing)收费。

## 按用量计费

按用量计费适用于超出套餐限额的付费套餐客户。它让你使用我们的服务时不必担心限额或任何合同义务。

按用量计费按月结算，目前对 EAS Build 和 EAS Update 启用。我们会在[账户的 Billing](https://expo.dev/settings/billing)上提供现有用量和任何超额费用的估算。当账户达到套餐所含 EAS Build 额度的 80% 和 100% 时，Expo 还会发送[电子邮件通知](/billing/usage-based-pricing#用量通知)。

## 附加项

### Enterprise Support

Enterprise Support 附加项仅面向新的 Enterprise 套餐订阅者，并视供应情况而定。主要功能包括：

- 获得专家提供的专业、长期支持
- 带服务级别协议（SLA）的直接沟通渠道支持
- 专属客户经理

- **[Enterprise Support 功能](https://expo.dev/solutions/enterprise)**：查看 Enterprise Support 附加项的完整功能列表。
