# 下一步

项目已经跑起来了，接下来做什么？

## 重置项目

想要一个干净的起点？运行重置脚本：它会把 **app** 中的现有文件移动到 **app-example**，然后新建一个只包含 `index.tsx` 文件的 **app** 文件夹。

:::tabs
:::tab npm
```sh
npm run reset-project
```
:::
:::tab yarn
```sh
yarn run reset-project
```
:::
:::tab pnpm
```sh
pnpm run reset-project
```
:::
:::tab bun
```sh
bun run reset-project
```
:::
:::

## 开发、评审与部署

查阅「开发（Develop）」板块，创建 [UI 元素](/develop/user-interface/splash-screen-and-app-icon)、添加[单元测试](/develop/unit-testing)、引入[原生模块](/config-plugins/introduction)等等。开发完成后，可以把应用分享给团队成员[评审](/review/overview)，最终[构建](/deploy/build-project)并[提交到应用商店](/deploy/submit-to-app-stores)。

## 分步指南

如需从头到尾跟随分步指南，用 Expo 构建一个完整的应用，请看[教程](/tutorial/introduction)。
