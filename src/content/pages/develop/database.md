# 数据库

大多数应用都需要数据在单个会话之外持续存在。云托管数据库可以保存应用数据，并让数据在不同设备与用户之间保持同步。

## Convex

[Convex](https://www.convex.dev/) 是一个基于 TypeScript 的数据库，无需管理集群，也无需使用 SQL 或 ORM。它通过 WebSocket 提供实时更新，非常适合响应式（reactive）应用。

- [使用 Convex](/guides/using-convex) —— 使用 Convex 为应用添加数据库。

## Supabase

[Supabase](https://supabase.com/) 是一个应用开发平台，提供托管的后端服务，包括 Postgres 数据库、用户身份验证、文件存储、边缘函数（Edge Functions）、实时同步，以及向量与 AI 工具包。

- [使用 Supabase](/guides/using-supabase) —— 使用 Supabase 添加 Postgres 数据库与用户身份验证。

## Firebase

[Firebase](https://firebase.google.com/) 同样是一个应用开发平台，提供实时数据库、云存储、身份验证、崩溃报告、分析等托管后端服务。它构建在 Google 的基础设施之上，可自动扩展。

- [使用 Firebase](/guides/using-firebase) —— 上手 Firebase JS SDK 与 React Native Firebase。
