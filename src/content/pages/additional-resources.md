# 其他资源

下面的资源有助于了解 Expo 工具和服务。

## 外部资源

### Expo 团队沟通

- [博客](https://expo.dev/blog)：我们的官方博客，每月发布版本说明，并在不固定的时间发布其他与 Expo 相关的内容。
- [更新日志](https://expo.dev/changelog)：我们的官方更新日志，在不固定的时间发布关于 EAS、Web 仪表板和其他 Expo 服务相关变更的信息。

### GitHub

- [expo/expo](https://github.com/expo/expo)：Expo Go、SDK、文档和 Expo CLI。
- [expo/eas-cli](https://github.com/expo/eas-cli)：构建、提交和更新 Android 与 iOS 应用的最快方式。
- [expo/examples](https://github.com/expo/examples)：集成和其他示例。
- [expo/config-plugins](https://github.com/expo/config-plugins)：用于与第三方包协作的 Expo 配置插件。
- [expo/snack](https://github.com/expo/snack)：从浏览器构建应用。
- [expo/vscode-expo](https://github.com/expo/vscode-expo)：用于使用 Expo 工具的 VS Code 扩展。
- [expo/vscode-expo-theme](https://github.com/expo/vscode-expo-theme)：Expo 团队创建的 VS Code 主题。
- [expo/fyi](https://github.com/expo/fyi)：Expo 工具和服务的故障排除指南。
- [expo/orbit](https://github.com/expo/orbit)：从 macOS 菜单栏、Windows 任务栏或 Linux 系统托盘启动构建并打开模拟器。
