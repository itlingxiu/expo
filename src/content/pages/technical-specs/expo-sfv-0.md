# Expo Structured Field Values

HTTP 的 Structured Field Values（[IETF RFC 8941](https://tools.ietf.org/html/rfc8941)）是一项提案，用于规范化标头语法并便于表达嵌套数据。

由于它仍在制定中，Expo 维护一个自定义版本，只实现 [IETF RFC 8941](https://tools.ietf.org/html/rfc8941) 所定义协议的以下子集：

- 所有键值
- 字符串、整数和十进制项
- 字典
