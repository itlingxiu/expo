# 回滚

EAS Update 支持两种回滚：

- 回滚到先前已经发布的更新。
- 回滚到构建中嵌入的更新。

第一种会让客户端回到某一次已经发布过的更新；第二种会让客户端运行构建时嵌进去的那份更新。

## 开始回滚

要开始一次回滚，在项目中运行以下命令：

```sh
$ eas update:rollback
```

终端中会出现交互式向导，协助你选择要执行的回滚类型，并完成这次回滚。

## 回滚到先前发布的更新

上述命令会重新发布一个先前已经发布过的更新，从而在功能上把客户端回滚到该更新。

## 回滚到构建中嵌入的更新

上述命令会指示客户端运行构建里已经嵌入的那一份更新。

## 回滚之后再次发布

回滚完成之后如果再次发布更新，所有客户端都会收到这份新发布的更新。
