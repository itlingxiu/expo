# iOS 开发者模式

:::note
不适用于使用企业签名（enterprise provisioning）签名的构建，也不适用于安装在 iOS 模拟器上的任何构建。
:::

iOS 16+ 的设备必须先开启系统级的开发者模式（Developer Mode），才能运行安装好的内部分发构建（包括 EAS 构建的）或本地开发构建。有两条路径：直接在设备上启用，或把设备连接到装有 Xcode 的 Mac。

## 启用开发者模式

**前置条件：** 一台运行 iOS 16 或更高版本的设备；只有这些设备需要开发者模式。这些步骤每台设备只需执行一次。

### 直接在一台 iOS 设备上

先安装开发构建 —— 构建创建后，按照 EAS 仪表盘的说明安装它。点击应用图标会弹出一个提示，要求启用开发者模式；按 OK。然后前往 设置 > 隐私与安全性 > 开发者模式，打开开关，iOS 提示时按 重新启动。重启后解锁设备；会出现系统提示 —— 按 打开，需要时输入密码。开发者模式随即开启，可以使用内部分发/本地开发构建。它随时可以关闭，但重新开启需要重复同样的流程。

### 把 iOS 设备连接到 Mac

:::note
按照下面的步骤操作之前，Mac 上必须已安装 Xcode。
:::

这种方法不需要先安装构建。用 USB 把设备连接到 Mac，出现"要信任此电脑吗？"提示时按 信任。在 Xcode 中，使用 Xcode > Open Developer Tool > Device Hub，在侧边栏选择设备，Device Hub 会显示"Enable Developer Mode"及说明。在设备上，打开 设置 > 隐私与安全性 > 开发者模式，打开开关，按 重新启动。重启后，解锁设备，在系统提示上按 打开，输入密码。开发者模式随即启用；关于关闭后需重复流程的说明同上。
