# 使用分析

借助分析服务，你可以观察人们如何使用你的应用。数据让你"在改进应用时采取有据可依的方法"。以下是 Expo 与 React Native 领域中广泛使用的分析服务提供商。

:::note
大多数分析 SDK 需要配置自定义原生代码，而原生代码无法在 Expo Go 中配置。但你可以创建[开发构建](/develop/development-builds/introduction)，这样就能使用下面列出的任何服务。
:::

## 提供商

- **Google Firebase Analytics** —— [rnfirebase.io/analytics/usage](https://rnfirebase.io/analytics/usage)：添加 React Native Firebase Analytics 的指引。
- **Segment** —— [segment.com 文档](https://segment.com/docs/connections/sources/catalog/libraries/mobile/react-native/)：添加 Segment Analytics SDK 的指引。
- **Amplitude** —— [Amplitude TypeScript React Native 文档](https://www.docs.developers.amplitude.com/data/sdks/typescript-react-native/)：添加 Amplitude Analytics SDK 的指引。
- **AWS Amplify** —— [AWS Amplify React Native 分析文档](https://docs.amplify.aws/lib/analytics/getting-started/q/platform/react-native/)：添加 AWS Amplify Analytics 的指引。
- **Aptabase** —— [aptabase.com/for-react-native](https://aptabase.com/for-react-native)：集成指引；"可在 Expo Go 中工作。"
- **Astrolytics** —— [astrolytics.io/react-native](https://www.astrolytics.io/react-native)：集成指引；"可在 Expo Go 中工作。"
- **PostHog** —— [posthog.com/docs/libraries/react-native](https://posthog.com/docs/libraries/react-native)：集成指引；"可在 Expo Go 中工作。"
- **Dreambase** —— [dreambase.ai/docs](https://dreambase.ai/docs)：在 Expo 与 Supabase 项目中跟踪用户行为与应用性能的指引。
