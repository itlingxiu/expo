# 使用内容管理系统（CMS）

**内容管理系统（CMS）** 是一个平台，让你无需编写自定义后端代码，就能创建、管理和组织博客文章、图片、商品信息等数字内容。使用 CMS 可以节省大量开发时间，并让非技术用户（例如编辑和营销人员）通过易用的界面轻松更新应用内容。

把 CMS 集成到 Expo 与 React Native 应用中，可以远程管理和更新内容、即时向用户推送新信息，并在不发布新应用更新的情况下扩展内容运营。

以下是 Expo 与 React Native 项目可以考虑的一些常用 CMS：

- [Strapi](https://strapi.io/integrations/expo) —— 了解如何把 Strapi 集成到 Expo 应用中。
- [Sanity](https://www.sanity.io/docs/visual-editing/visual-editing-with-react-native) —— 按照 Sanity 的指南，在 Expo 与 React Native 中实现可视化编辑。
