# 指南概览

## 开发流程

通过[使用 Expo 构建应用](/workflow/overview)来了解核心开发循环的心智模型。本节还深入介绍你在开发、部署和维护应用时可能需要的其他配置与工作流，内容涵盖[应用配置](/workflow/configuration)、[权限](/guides/permissions)、[通用链接（Universal Links）](/linking/into-your-app)、[自定义原生代码](/workflow/continuous-native-generation)、[Web](/workflow/web)等。

了解如何使用 [Expo Router](/router/introduction) 库提供的各种导航功能。它还包括该库提供的完整 [Hooks API](/versions/latest/sdk/router#hooks)，以及导航的其他方面，如[身份验证](/router/advanced/authentication)、[重定向](/router/reference/redirects)、[测试](/router/reference/testing)等。

## Expo Modules API

了解如何使用 [Expo Modules API](/modules/overview) 在应用中添加和使用原生模块。

## 教程

如果你在寻找 Expo 和 EAS 的分步教程，请参阅[教程部分](/tutorial/overview)，其中包括[使用 Expo 构建应用](/tutorial/introduction)和[使用 EAS 服务](/tutorial/eas/introduction)的完整教程。
