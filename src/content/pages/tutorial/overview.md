# 教程概览

「学习（Learn）」板块包含一组教程与指南，帮助你学习 Expo 和 Expo Application Services (EAS)：

1. [**Expo 教程**](/tutorial/introduction) —— 推荐给希望自己手写代码的 Expo 新手。逐步构建一个运行在 Android、iOS 和 Web 上的 Expo 应用。
2. [**使用 AI 构建教程**](/tutorial/build-with-ai/introduction) —— 通过指挥 AI 编程代理构建你的第一个应用，无需编程经验。覆盖从零搭建工具链，并在每一步用手机验证应用。
3. [**EAS 教程**](/tutorial/eas/introduction) —— 学习使用 EAS 构建 Android 和 iOS 应用，覆盖 EAS Build、Update 和 Submit 工作流。
4. [**CI/CD 教程**](/tutorial/cicd/introduction) —— 使用 EAS Workflows 自动化构建、测试和发布 Expo 应用。覆盖开发、预览和生产流水线，从第一个 workflow 文件一直到基于标签的发布和 Web 部署。
