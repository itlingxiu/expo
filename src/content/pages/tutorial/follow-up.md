# 学习资源

示例应用已经完成，接下来了解构建它所使用的技术。

## 把项目构建成应用

要在自己的电脑上开始创建新应用，可以依次使用 `npx create-expo-app@latest`，并[设置开发环境](/get-started/set-up-your-environment)。

### 推荐资源

创建新项目之后，可以进一步了解这些工具和概念，它们会在应用开发过程中帮到你：

- [开发工具](/develop/tools)：一份 Expo 工具参考，涵盖应用构建过程中的多个方面。
- [开发构建](/develop/development-builds/introduction)：使用开发构建可以完全掌控应用的构建过程，并在设备或模拟器上测试应用。
- [开发概览](/workflow/overview)：一份高层概览，说明用 Expo 开发应用的关键概念，以及核心开发循环的流程。
- [Expo Router](/router/introduction)：我们走过了 Expo Router 的基础，并实现了一个标签导航器。参见其文档以进一步了解这个库。
- [应用图标](/develop/user-interface/splash-screen-and-app-icon#app-icon)和[启动画面](/develop/user-interface/splash-screen-and-app-icon#splash-screen)：可以进一步了解如何自定义应用图标和启动画面。也可以查阅[应用配置参考](/workflow/configuration)，了解 **app.json** 中可以配置的属性。
- 向应用商店进行[应用分发](/deploy/build-project)和[提交](/deploy/submit-to-app-stores)：阅读这些资料，了解应用准备发布后如何发布并提交到应用商店。
- [调试](/debugging/runtime-issues)：有时会出问题。出问题时，可以用调试工具定位并修复错误。

## 学习

### React

我们使用了 React 组件和 API。扎实理解 React，是用 Expo 构建应用的基础。建议阅读 React 文档的 [Quick Start](https://react.dev/learn) 和 [Hooks](https://react.dev/reference/react/hooks) 部分。

### React Native

开发本教程应用时，我们大量使用了 React Native。可以从 [React Native 入门指南](https://reactnative.dev/docs/getting-started) 开始了解。也可以查看以下文档：

- [View API 参考](https://reactnative.dev/docs/view)
- [Text API 参考](https://reactnative.dev/docs/text)
- [平台特定代码](https://reactnative.dev/docs/platform-specific-code)
- [在列表中展示数据](https://reactnative.dev/docs/using-a-listview)

我们用 Flexbox 布局组件。可以查看以下资料进一步了解：

- [高度与宽度](https://reactnative.dev/docs/height-and-width)
- [使用 Flexbox 布局](https://reactnative.dev/docs/flexbox)

### 手势与动画

要进一步了解如何实现不同类型的手势和动画，建议阅读以下文档：

- [React Native Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler/docs/)
- [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/getting-started)
