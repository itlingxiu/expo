# 教程：用 AI 智能体构建应用

在本教程中，你将构建一个同时面向 Android、iOS 和 Web 的完整应用，而无需自己写代码。你将指挥一个 AI 编程智能体（例如 Claude Code、Codex 或 Cursor），并在每一步之后用自己的手机实时查看结果。

本教程面向**构建者**：有应用想法、但没有编程背景的人。如果你更想自己学习写代码，请改学 [Expo 教程](/tutorial/introduction)。它构建的是同一个应用，一次一个代码片段。

## 你将构建什么

你将构建 **StickerSmash**。这个应用可以让你选择一张照片、在上面放置表情贴纸、用手指移动和缩放贴纸，并把结果保存到相册：

## 本教程如何进行

每一章都遵循同一套循环：

1. **提示**：把建议的提示词粘贴到你的 AI 智能体中。
2. **构建**：智能体编写代码，应用会在几秒内更新到你的手机上。
3. **验证**：直接在手机上确认应用是否按你的要求工作。
4. **再次提示**：如果哪里看起来不对，把你看到的现象告诉智能体，让它修复。

你是产品负责人和测试者。智能体是程序员。

AI 智能体每次的产出不会完全相同，所以你的应用不会与我们的截图像素级一致。这是预期行为。提示词描述的是你想要的结果，截图展示的是你大致应该看到的样子。你可以按自己的口味修改提示词：换不同的颜色、改按钮上的文案，把它做成你自己的。

## 你需要准备什么

- 一台运行 macOS、Windows 或 Linux 的电脑。
- 一部 Android 或 iOS 手机。
- 大约一小时。第一章会从零带你安装每一个工具，所以事先不需要任何环境。
