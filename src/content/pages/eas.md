# Expo Application Services（EAS）

Expo Application Services（EAS）是 Expo 团队为 Expo 和 React Native 应用打造的深度集成的云服务。

完整介绍请见 [expo.dev/services](https://expo.dev/services)，或点击下方链接了解如何开始使用。

- [EAS Workflows](/eas/workflows/introduction)：通过 CI/CD 作业自动化你的开发与发布工作流。
- [EAS Build](/build/introduction)：在云端编译并签名带有自定义原生代码的 Android/iOS 应用。
- [EAS Submit](/deploy/submit-to-app-stores)：在云端通过一条 CLI 命令将应用上传到 Google Play Store 或 Apple App Store。
- [EAS Hosting](/eas/hosting/introduction)：部署 Expo Router 和 React Native Web 应用及 API 路由。
- [EAS Update](/eas-update/introduction)：修复小 bug，将快速修复直接推送给最终用户。
- [EAS Observe](/eas/observe/introduction)：监控应用在生产环境中的性能。
- [EAS Metadata（预览版）](/eas/metadata)：上传应用发布所需的全部商店信息。
- [EAS Insights（预览版）](/eas-insights/introduction)：查看项目在性能、使用量和覆盖范围方面的分析数据。
