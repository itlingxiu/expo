# @react-native-picker/picker 包参考

> 支持平台：Android、iOS、macOS、Web、Expo Go。

:::note
[`@expo/ui`](/versions/latest/sdk/ui/drop-in-replacements/picker) 为 `@react-native-picker/picker` 提供了直接替代方案，在 Android 上由 Jetpack Compose 驱动，在 iOS 上由 SwiftUI 驱动。
:::

一个可访问系统 UI 以便在多个选项中进行选择的组件。

## 安装

:::tabs
:::tab npm
```sh
npx expo install @react-native-picker/picker
```
:::
:::tab yarn
```sh
yarn expo install @react-native-picker/picker
```
:::
:::tab pnpm
```sh
pnpm expo install @react-native-picker/picker
```
:::
:::tab bun
```sh
bun expo install @react-native-picker/picker
```
:::
:::
