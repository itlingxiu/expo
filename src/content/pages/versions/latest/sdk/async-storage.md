# @react-native-async-storage/async-storage 包参考

Async Storage 是异步、未加密、持久化的键值存储方案。

> 支持平台：Android、iOS、tvOS、macOS、Web、Expo Go。

## 安装

:::tabs
:::tab npm
```sh
npx expo install @react-native-async-storage/async-storage
```
:::
:::tab yarn
```sh
yarn expo install @react-native-async-storage/async-storage
```
:::
:::tab pnpm
```sh
pnpm expo install @react-native-async-storage/async-storage
```
:::
:::tab bun
```sh
bun expo install @react-native-async-storage/async-storage
```
:::
:::

也可参考[官方安装说明](https://react-native-async-storage.github.io/2.0/Installation/)。
