# react-native-gesture-handler 包参考

> 支持平台：Android、iOS、Web、Expo Go。

`react-native-gesture-handler` 是一个用于处理复杂手势的库。以下是其 README 中的介绍：

> 该库提供的 API 暴露了移动平台特有的触控与手势处理和识别的原生能力。它支持定义复杂的手势处理和识别逻辑，这些逻辑 100% 运行在原生线程中，因此具有确定性。
