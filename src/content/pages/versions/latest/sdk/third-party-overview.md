# Expo Go 支持的第三方库

Expo Go 演练场让学生和学习者可以快速尝试构建原生 Android 与 iOS 应用。它支持一份经过挑选的第三方库清单：这些库由社区驱动，为常见应用功能提供 API，并会随每个 Expo SDK 版本进行测试。

这一节列出的库与其他第三方库的区别在于：前者的支持已经内置在 Expo Go 环境中。使用开发构建时，你可以选用任何自己需要的库。
