# @shopify/react-native-skia 包参考

> 支持平台：Android、iOS、tvOS、Web、Expo Go。

`@shopify/react-native-skia` 把 Skia Graphics Library 带到 React Native。Skia 是 Google Chrome 与 Chrome OS、Android、Flutter、Mozilla Firefox 与 Firefox OS 以及许多其他产品的图形引擎。

## 安装

:::tabs
:::tab npm
```sh
npx expo install @shopify/react-native-skia
```
:::
:::tab yarn
```sh
yarn expo install @shopify/react-native-skia
```
:::
:::tab pnpm
```sh
pnpm expo install @shopify/react-native-skia
```
:::
:::tab bun
```sh
bun expo install @shopify/react-native-skia
```
:::
:::

### Web

如果要在 Web 上使用 Skia，需要按照 [Web 安装说明](https://shopify.github.io/react-native-skia/docs/getting-started/web/#expo) 加载 CanvasKit。
