# @react-native-community/slider 包参考

> 支持平台：Android、iOS、Web、Expo Go。

:::warning
[`@expo/ui` 提供了直接替代组件](/versions/latest/sdk/ui/drop-in-replacements/slider)，可替换 `@react-native-community/slider`。Android 上由 Jetpack Compose 驱动，iOS 上由 SwiftUI 驱动。
:::

这个组件库提供滑块控件的系统界面，用户可以拖动锚点，在一段取值范围内进行选择。

## 安装

:::tabs
:::tab npm
```sh
npx expo install @react-native-community/slider
```
:::
:::tab yarn
```sh
yarn expo install @react-native-community/slider
```
:::
:::tab pnpm
```sh
pnpm expo install @react-native-community/slider
```
:::
:::tab bun
```sh
bun expo install @react-native-community/slider
```
:::
:::
