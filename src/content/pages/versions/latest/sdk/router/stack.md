# Router Stack 包参考

> 支持平台：Android、iOS、tvOS、Web、Expo Go。

这是一个 Expo Router API，提供 Stack 导航器、工具栏和屏幕组件。

> 有关安装和配置，请参阅 [Expo Router](/versions/latest/sdk/router) 参考。

## 用法

```tsx
import { Stack } from 'expo-router';

export default function Layout() {
  return <Stack />;
}
```

关于如何使用栈导航器的更多信息，请阅读栈布局指南：

- [Stack 布局](/router/advanced/stack)：了解如何在 Expo Router 中使用 Stack 布局。

## API

```js
import { Stack } from 'expo-router';
```
