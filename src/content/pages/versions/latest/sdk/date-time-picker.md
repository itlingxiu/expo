# @react-native-community/datetimepicker 包参考

:::note
[`@expo/ui` 提供了直接替换组件](/versions/latest/sdk/ui/drop-in-replacements/datetimepicker)，可替代 `@react-native-community/datetimepicker`。Android 上由 Jetpack Compose 驱动，iOS 上由 SwiftUI 驱动。
:::

一个用于访问系统日期与时间选择界面的组件。

> 支持平台：Android、iOS、Expo Go。

> 本页包含一段系统日期与时间选择器的演示。

## 安装

:::tabs
:::tab npm
```sh
npx expo install @react-native-community/datetimepicker
```
:::
:::tab yarn
```sh
yarn expo install @react-native-community/datetimepicker
```
:::
:::tab pnpm
```sh
pnpm expo install @react-native-community/datetimepicker
```
:::
:::tab bun
```sh
bun expo install @react-native-community/datetimepicker
```
:::
:::

也可参考[官方安装说明](https://github.com/react-native-datetimepicker/datetimepicker#getting-started)。
