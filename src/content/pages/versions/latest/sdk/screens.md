# react-native-screens 包参考

> 支持平台：Android、iOS、tvOS、Web、Expo Go。

`react-native-screens` 提供原生原语来表示屏幕，而不是普通的 `<View>` 组件，从而更好地利用操作系统围绕屏幕的行为与优化。这项能力主要由库作者使用，大多数应用开发者不太会直接使用。它也为 React Navigation 的 [`createNativeStackNavigator`](https://reactnavigation.org/docs/native-stack-navigator) 提供所需的原生组件。
