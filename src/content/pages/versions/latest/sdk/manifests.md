# Manifests 包参考

> 支持平台：Android、iOS、tvOS、Expo Go。

## 安装

:::tabs
:::tab npm
```sh
npx expo install expo-manifests
```
:::
:::tab yarn
```sh
yarn expo install expo-manifests
```
:::
:::tab pnpm
```sh
pnpm expo install expo-manifests
```
:::
:::tab bun
```sh
bun expo install expo-manifests
```
:::
:::

## API

```js
import * as Manifests from 'expo-manifests';
```
