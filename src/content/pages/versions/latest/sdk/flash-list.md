# @shopify/flash-list 包参考

> 支持平台：Android、iOS、tvOS、Web、Expo Go。

`@shopify/flash-list` 是一个"快速且高性能的 React Native 列表"组件，可以直接替换 React Native 的 `<FlatList>` 组件。它"在底层回收组件以最大限度地提升性能"。

## 安装

:::tabs
:::tab npm
```sh
npx expo install @shopify/flash-list
```
:::
:::tab yarn
```sh
yarn expo install @shopify/flash-list
```
:::
:::tab pnpm
```sh
pnpm expo install @shopify/flash-list
```
:::
:::tab bun
```sh
bun expo install @shopify/flash-list
```
:::
:::
